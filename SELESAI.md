## 💻 TECH STACK

- **Backend**: Laravel 12
- **Frontend**: Blade Templates + Tailwind CSS + Alpine.js
- **Database**: SQLite
- **Auth**: Laravel Built-in
- **Styling**: Tailwind CSS (from CDN)
- **Components**: Alpine.js (from CDN)
